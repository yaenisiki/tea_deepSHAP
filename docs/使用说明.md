# 公开版使用说明

本仓库公开当前论文使用的分析代码，包括模型定义、候选超参数、验证流程和绘图函数。原始数据、模型权重、真实逐样本预测、真实 SHAP 数值、审计记录、原始冻结配置和论文内部文件均未随仓库提供。

`examples/synthetic_tea.csv` 的全部数值由随机过程独立生成，没有从真实茶样计算均值、分布、扰动值或拟合权重。样例沿用论文所需的列名、地区名称和年度行数，只用于检查代码，不能支持论文结论。

## 在 Windows 上快速运行

在本目录打开 PowerShell，按 README 创建环境并安装依赖，然后运行：

```powershell
$env:TEA_DATA_PATH = (Resolve-Path "examples/synthetic_tea.csv").Path
$env:TEA_DATASET_VERSION = "synthetic-example-v1 (not study observations)"
python -m unittest discover -s tests -v
python run_lwt.py --mode fast --only "Extra Trees" --outer-limit 1 --skip-loro --output outputs/demo_smoke
python verify_release.py
```

一折测试只用于确认程序能运行。完整计算按 README 的 `paper → freeze → temporal → SHAP → render` 顺序执行，不应以一折测试结果作为正式模型比较结果。重复运行应使用新的输出路径。

## 使用自己的数据

将 `TEA_DATA_PATH` 指向本人获准使用的 CSV/XLSX。默认读取 XLSX 的 `Sheet1`，也可设置 `TEA_SHEET`。输入格式及固定队列要求详见 README；本次整理保留了原论文设计检查，没有把它改成适用于任意样本量的通用建模工具。

运行不会读取或下载本项目的保密模型；模型在本机从所提供的数据重新拟合。原论文精确数值仍需要原始数据及对应的运行条件，合成样例不能复现原论文数值。

输出可能包含逐样本预测、可追踪的行号、SHAP 和样本散点。这些信息对真实数据仍可能敏感，应保留在本地。`.gitignore` 采用白名单，但不能阻止手工强制添加或覆盖一个已获准文件；上传前应运行检查并查看 Git 的暂存清单。

## 数据与代码声明

文稿应准确表述“分析代码公开，原始数据和训练权重不公开”。可参考 [声明模板](DATA_AND_CODE_AVAILABILITY.md)，填写正式仓库网址、版本及真实的数据访问条件。没有承诺“合理请求即可获取”，也没有假定所有期刊接受同一种数据政策。

本次发布适配包括：把本机固定数据路径改为环境变量输入；移除本机依赖目录注入；补充从新开发结果生成冻结配置的入口；将私有来源审计改为单独提供，缺失时明确跳过相应敏感性分析。模型候选空间、嵌套验证逻辑和 SHAP 可加性检查保留。
